# battleship

A modern Battleship game built with HTML, CSS, and JavaScript (ES Modules).
The project uses factory functions, objects, and a fully modular architecture to keep the code clean and scalable.

Battleship Rules - https://en.wikipedia.org/wiki/Battleship_(game)
The online version or the original version i took inspiration from - http://en.battleship-game.org/

Features:

Classic Battleship gameplay

Drag-and-drop ship placement with rotation

Smart collision + boundary detection

Player vs Computer mode

Responsive UI with clear hit/miss feedback

Tech & Concepts:

Vanilla JS (modules)

Factory functions (Ship, Player, Gameboard)

DOM + logic separation

Custom drag & drop system

Run the Project:

Just open index.html in your browser — no setup needed.

or here's the live preview link - https://anuj-kumar0.github.io/battleship/
